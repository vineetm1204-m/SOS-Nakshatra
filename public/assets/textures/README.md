# Earth Texture Assets & Provenance

## Imagery Sources & Attribution
- **Source:** NASA Earth Observatory (Visible Earth: Blue Marble Next Generation, Reto Stöckli / NASA GSFC) & Three.js Examples Repository (Mr.doob).
- **Projection:** Seamless cylindrical equirectangular (Plate Carrée), 2:1 aspect ratio.
- **License:** Public Domain (NASA open data policy) / MIT License (Three.js planet textures).

## File Descriptions
1. **`earth-day.jpg`** (2048x1024, JPEG)
   Photorealistic True-color Earth daytime surface map showing natural landforms, continental vegetation, and deep ocean bathymetry.
2. **`earth-specular.jpg`** (2048x1024, JPEG)
   Water reflectance mask separating matte continental landmasses (black) from reflective ocean bodies (white) for realistic solar glint.
3. **`earth-normal.jpg`** (2048x1024, JPEG)
   Tangent-space surface normal map providing mountain range topography, continental shelf relief, and lighting shadows.
4. **`earth-clouds.png`** (1024x512, PNG with Alpha)
   Semi-transparent cloud formations map for dual-layer atmospheric depth.
